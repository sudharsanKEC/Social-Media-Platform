Installing redux toolkit:
    npm install @reduxjs/toolkit react-redux

    The redux is mainly used for the global state management in react js. 
    When we are building frontend of projects we have the situations where we pass the data from one component to the other as props.
    But when the project grows and the frontend becomes huge, then that approach of passing the data using props will not be ideal. The datas will become messy for managing.
    Some example of those problems:
            many pages need same data
            login info needed everywhere
            JWT token needed everywhere
            user profile needed everywhere
        Passing data through props becomes messy.
    And redux was introduced to solve that problem. Redux solves this by creating one central place to store shared app data.
    In our project, we have not directly used redux. Instead we have used redux toolkit. Using redux like traditionally had a huge setup but redux toolkit helps us to reduce that.
    The command to install redux toolkit is: npm install @reduxjs/toolkit react-redux
    After installing it we want to store the necessary data in a central store in redux called "Store".
    And from that we can access and manage every data.

        Before writing the configuration codes in those files(store.js, authSlice.js), we want to know some prerequisites about the redux's centralized management of data.
        Previously, we know that redux manages the app data in centralized place and that place is called store.
        So, store is the central container that holds app wide data.
        And the store itself has seperated into multiple parts called slices.
        And those slices might be for authentication, post or anyother things.
        So in the authSlice.js we paste the code for slices used for every particular job. 
        And the createSlice() is used for creating a slice for specific use case and in that function we want to pass the details like:
            i)   name of the slice(name: "auth").
            ii)  initialState(which contains the initial state of the variables in the slices)
